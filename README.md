# AgentPlay Companion releases

Signed builds of AgentPlay Companion and the update feed its installed copies read. No source code here.

- **Already using AgentPlay?** You don't need anything from this page: the app checks here once a day and updates itself.
- **New install (Mac, Apple silicon, macOS 14+):** download `AgentPlay-Companion-<version>-arm64.dmg` from the latest release and follow the install steps in its notes. Builds are not notarized by Apple yet, so the first install uses a Terminal command; every update after that is automatic.

Every update is signed, and the app refuses any download whose signature doesn't match the key built into it.
